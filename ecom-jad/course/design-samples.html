Before you install

Claude Code is a terminal tool. It is not a website and not a chat window — you run it from a folder on your own machine, and it can read and change the files in that folder. That is exactly why the next module makes you take a backup first.

Check your plan first

Claude Code requires a Pro, Max, Team, Enterprise or Console account. The free Claude.ai plan does not include it. Paying for a plan does not mean unlimited use — every plan has usage limits.

Install

Pick the line for your system. If one command errors, you are probably in the other Windows shell: PowerShell shows PS C:\ at the prompt, CMD shows C:\ without the PS.

macOS · Linux · WSL
$ curl -fsSL https://claude.ai/install.sh | bash
Windows PowerShell
PS> irm https://claude.ai/install.ps1 | iex
Windows CMD
C:\> curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

Prove it worked

Any terminal
$ claude --version
→ prints a version number, for example 2.1.211 (Claude Code)

$ claude doctor
→ read-only diagnostics: install health, settings errors, suggested fixes
If the command is not found

Close the terminal and open a new one — a fresh shell picks up the changed path. If it still fails, you most likely have a second installation or an old alias left over. Run claude doctor and read what it reports before installing anything again.

What you should have now

  • A terminal that prints a version number.
  • A plan that actually includes Claude Code.
  • No secret keys pasted anywhere.

Source: Claude Code documentation, Advanced setup — code.claude.com/docs/en/setup

14 · Shopify CLI, AI Toolkit and the theme workflow

Two different connections, often confused

These are not the same thing, and mixing them up is the single most common reason a beginner believes an AI tool can edit a live store when it cannot.

Fig 14.1Simplified illustration The knowledge layer and the access layer are installed separately and do different jobs. Admin settings — products, payments, domain, taxes, apps — sit outside both and need Shopify Admin.

Check yourself

If you cannot name which store your terminal is authenticated against, stop and run the store check before any push. Pushing to the wrong store is recoverable only if you took the backup.

20 · Channel choice, testing, KPIs and scaling

Reading the funnel, not the headline number

A platform reports what it can attribute. Your store reports what actually happened. When they disagree, write down the difference — do not pick the nicer number.

SymptomWhere to look first
No delivery at allPayment, policy review, audience size, budget, bid
Impressions but few clicksHook, first frame, relevance — not the CTA
Clicks but no landing page viewsLoad speed, broken link, or a measurement fault
Visits but no product interactionMessage match, price, trust, clarity of the offer
Carts but few checkoutsCTA, mobile bug, an unexpected extra step
Checkouts but few purchasesPayment method, currency, terms, checkout friction
Purchases in the store, none in the platformPixel, consent, event deduplication, domain, attribution
